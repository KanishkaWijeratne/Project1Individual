How to Compile and Run:

Navigate to the project directory and compile the Java source files:

javac *.java

Run the test driver:

java TestDriver

The driver prints the results of the tests and whether it passes or fails.

The driver is testing the Product, Client, ProductList, ClientList, and wishlistitem(NOTE: I wrote a basic one for testing the Client and Minh in Group 8 is working on this for his individual task.
